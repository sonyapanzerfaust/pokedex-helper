# Pokédex Helper 1.2

## Запуск

В Windows x64 распакуй ZIP и запусти PokedexHelper.exe. В Linux x64 распакуй tar.gz и запусти ./PokedexHelper. Данные лежат рядом с приложением в папке data.

## Языки интерфейса

В настройках и при первом запуске доступны русский, английский, японский,
французский, итальянский, немецкий и испанский. На всех семи языках доступны
интерфейс, прохождение, условия и места встреч, сообщения приложения об ошибках.
Переводы пока не вычитаны носителями. Язык приложения
не меняет поддержку ROM: основной маршрут по-прежнему рассчитан на Platinum USA.
Подробнее: [покрытие локализаций](docs/localization.md).

В Settings → Language доступны все семь языков. Новый профиль открывается на английском. Для существующего файла настроек по умолчанию выбран русский. В мастере язык можно изменить уже на первом экране. Настройка сохраняется в preferences-v1.json. Словари загружаются с диска.

Инструкции по добавлению языков и проверке переводов находятся в docs/localization.md. Общий реестр языков используется мастером запуска, настройками и загрузчиком словарей. Код форматирования использует Intl и английский fallback. Приложение использует утверждённый порядок из route-research/ORDERED_ROUTE.json. Сначала Platinum, затем Emerald; базовый план включает восемь партий Pal Park.

## Запуск

На Windows распакуй ZIP для архитектуры системы в отдельную папку и запусти PokedexHelper.exe. Рядом с программой должны остаться resources и файлы Electron. В установленной рабочей копии по-прежнему работает Start-Helper.ps1. Клиент находит прежние настройки, игровые пути и резервные копии в Documents/PokedexHelper. Старые отметки остаются в helper-state.json, новые настройки записываются в preferences-v1.json. Для переноса между компьютерами доступны экспорт и импорт JSON. Ручная галочка прежней версии могла означать получение в доноре, поэтому статус такой задачи хранится отдельно от регистрации в Platinum.

Для разработки в VS Code открой рабочую папку PokedexHelper. В терминале PowerShell выполни `./runtime/electron.exe`. Для сборки архива используй `node scripts/build.cjs win32-x64` или `node scripts/build.cjs win32-ia32`.

## Подключение

При первом запуске подтверди копирование прежних данных. На Windows Helper пробует создать PokedexHelperData в корне диска документов. Если обычной учётной записи недоступна запись, выбери родительскую папку с латинским путём. Точный путь виден в настройках. Привязка хранится в Documents/PokedexHelper/data/library-location.json. При отключённом диске верни его и повтори подключение в настройках.

В «ROM-файлы» выбери игру и её файл. Внутренние копии Platinum называются games/platinum/game.nds и game.sav. Для импорта соседнего SAV появится отдельный запрос. В разделе «Сохранения» можно выбрать файл вручную. Старый файл сохраняется в backups перед подтверждённой заменой. Для миграции закрой прежний эмулятор после внутриигрового сохранения. Играть следует через кнопку Helper. Сохранение через меню игры обновляет тот же файл, который читает парсер. Для ручного режима ROM и эмулятор необязательны.

Helper устанавливает официальные дистрибутивы в emulators. Для установленных ранее melonDS 1.1 и mGBA 0.10.5 можно использовать сохранённые архивы Helper без загрузки. При ручном подключении выбери официальный архив. Установка с загрузкой требует подтверждения. Команда запуска, PID и код выхода записываются в logs/launch.jsonl. Вывод эмулятора хранится рядом.

## Источник прогресса

Единый модуль save.js читает только буфер байтов. Для DS ожидается raw 512 КиБ. Парсер проверяет длину, сигнатуры, тип блока и CRC16. Банки общих данных и PC выбираются независимо по двум счётчикам. Проверяются заголовок Pokédex, согласованность Seen/Caught и контрольные суммы расшифрованных PK4. Номер вида кодируется битом с индексом «National ID минус один». Для GBA принимается raw 128 КиБ с полным банком из 14 различных секций, общей ревизией и контрольными суммами. Регистрация в доноре отражает запись в его Pokédex, которая может сохраняться после обмена покемона.

Platinum предоставляет идентификатор тренера, язык, значки, завершение Лиги, National Dex, выход из Distortion World, команду, PC и сюжетную переменную выбора стартера. Для стадии ищется единственный подходящий представитель этой линии исходного тренера из Platinum, полученный на Route 201 на пятом уровне. При неоднозначности отображается базовая линия. Язык сохранения сам по себе не отличает картриджи США и Европы. Для основного ROM проверяется заголовок CPUE. Семейства D/P и FR/LG имеют общую структуру, версия донора задаётся при подключении. Настройки и последний проверенный снимок переживают перезапуск. При ошибке чтения интерфейс показывает причину и последние данные. Резервные копии доступны из боковой панели desktop.

## Маршрут

Основные этапы Platinum сохранили номера 01–15. После них следуют компактные доноры, эволюции и финальные события. Для вида кнопка «Способы получения» показывает варианты по играм, локациям, методу, группе встречи и уровню. Веса слотов относятся к таблице для указанного набора условий. Удочка сначала должна дать поклёвку, а для Honey Trees сначала выбирается группа. Веса из разных наборов условий нельзя складывать как шанс одной попытки. Ранние Honey Trees для Heracross и Munchlax можно отложить и вернуть. Пойманный в доноре вид регистрируется в основном счётчике только после попадания в Platinum.

Для DS-обмена подготовь вторую игру и доступ в Union Room, второго покемона и свободное место. Для Pal Park в Sinnoh открой National Dex, дойди до конца Route 221 и получи доступ к парку. В GBA-сохранении положи шесть подходящих покемонов в PC, убери HM-приёмы, исключи яйца. В оригинале нужен DS или DS Lite с GBA Slot-2 и совместимыми языками картриджей. Для эмуляции подключи GBA-картридж вместе с его батарейным сохранением. В главном меню Platinum выбери Migrate, затем поймай всех шестерых в Pal Park. Миграция игровыми средствами односторонняя, в D/P/Pt действует ограничение в шесть с одного GBA-картриджа за 24 часа. При необходимости используй рабочие копии игровых файлов.

### Исключение для Spiritomb

Обычный путь подробно описан в карточке Spiritomb. Если локальная связь Underground недоступна, можно отдельно восстановить только счётчик разговоров. Установи Odd Keystone на Route 209, сохранись в игре и закрой эмулятор. В отдельной папке сделай рабочую копию этого сохранения. Выполни `node scripts/spiritomb-info.cjs "путь/к/копии.sav"`. Команда читает копию, проверяет CRC и выводит две пары байтов и их точные адреса для текущего банка. В hex-редакторе открой именно копию, установи указанные байты счётчика и CRC, сохрани её и перепроверь командой parser.cjs. Запусти копию в отдельной игровой конфигурации, подойди к Hallowed Tower, поймай Spiritomb. Для регистрации в исходном прохождении используй обычный DS-обмен. Скрипт не записывает файлы. Формат счётчика подтверждают [SystemVars](https://github.com/pret/pokeplatinum/blob/main/src/system_vars.c), [таблица переменных](https://github.com/pret/pokeplatinum/blob/main/generated/vars_flags.txt) и [сценарий Route 209](https://github.com/pret/pokeplatinum/blob/main/res/field/maps/route_209/scripts.s).

### Manaphy без Pokémon Ranger

Оригинальный TRU Manaphy был подарком 50 уровня для английских Diamond и Pearl. В отдельной копии совместимого D/P через Event Injector инструмента PKSM на 3DS выбери историческую американскую карту TRU Manaphy за 2007 год. Получи подарок у курьера Poké Mart со свободной ячейкой команды, затем обменяй его в Platinum. Это восстановление исторического подарка. Оригинальный Pokémon Ranger и его миссии для этого варианта не требуются. [История дистрибуции](https://bulbapedia.bulbagarden.net/wiki/Manaphy_(Pok%C3%A9mon)), [документация Event Injector](https://github.com/FlagBrew/PKSM/wiki/Event-Injector).

На Windows тот же исторический подарок можно получить на отдельной копии Diamond/Pearl.

1. При закрытом эмуляторе подготовь копию донорского .sav в отдельной игровой папке. Скачай [архивную карту TRU Manaphy для D/P](https://github.com/projectpokemon/EventsGallery/blob/master/Released/Gen%204/hex%20extracted%20cards/ENG/001%20DP%20-%20TRU%20Manaphy%20(ENG)%20(Hex%20Extracted).pcd).
2. В исходном пакете выполни `node scripts/manaphy-gift.cjs "путь/к/карте.pcd"`. Скрипт проверяет SHA-256 и извлекает оригинальную запись подарка в новый TRU-Manaphy.pgt рядом с картой.
3. В отдельном Pokesav для **Diamond/Pearl** открой донорскую копию. В редакторе Mystery Gift включи Mystery Gift, загрузи .pcd в свободный слот Wonder Card и .pgt в свободный слот Gift. Выбери статус неполученного подарка и соответствующую карту, подтверди изменения и сохрани копию. [Описание слотов PCD/PGT](https://projectpokemon.org/editing/pokesav/pokesavmysterygift.html).
4. Запусти донорскую копию в melonDS. Оставь свободное место, поговори с курьером в Poké Mart и забери Manaphy. Через локальный DS-обмен перенеси его в Platinum и сохранись в игре. Helper увидит запись Caught при следующем чтении.

## Источники и атрибуция

Структуры формата сверены с официальным [PKHeX.Core](https://github.com/kwsch/PKHeX/tree/master/PKHeX.Core/Saves), включая SAV4, SAV4Sinnoh, SAV4Pt, SAV4DP, SAV4HGSS, SaveUtil, SAV4BlockDetection, Zukan4, SAV3 и PokeCrypto. PKHeX имеет лицензию GPL-3.0. JavaScript-декодер реализован отдельно по формату, приложение не включает бинарники или библиотеки PKHeX. Сюжетные переменные дополнительно сверены с [pret/pokeplatinum](https://github.com/pret/pokeplatinum).

Справочные таблицы основаны на данных [PokéAPI](https://github.com/PokeAPI/pokeapi/tree/master/data/v2/csv). Чтобы обновить таблицу, передай путь к каталогу CSV в scripts/route-data.ps1. Правила редких встреч проверялись по [Honey Tree](https://bulbapedia.bulbagarden.net/wiki/Honey_Tree), [Headbutt tree](https://bulbapedia.bulbagarden.net/wiki/Headbutt_tree), [Pal Park](https://bulbapedia.bulbagarden.net/wiki/Pal_Park) и [маршруту Copycat](https://bulbapedia.bulbagarden.net/wiki/Walkthrough:Pok%C3%A9mon_HeartGold_and_SoulSilver/Part_20). При выборе стратегий рассматривались [r/pokemonguide](https://www.reddit.com/r/pokemonguide/) и [обсуждение полного National Dex](https://www.reddit.com/r/pokemon/comments/oyjuy7/ive_written_the_most_comprehensive_guide_ever_to/).

Портативная сборка показывает имена видов в команде и коробках.
